# #595 Flow Audit — 路线裁决（≤500 字）

**问题主要位于"研究叠加层"，不是产品流程，更不是感知算法。**
产品 master 只有一条提交路径（逐 op `submit_read`，每 op 一次
`io_uring_submit`）。两轮矩阵稳健复现的唯一机制级事实是：**enter
可摊销**（R/C−A0：CPU −22%、吞吐 +28%）。d16 p99 +18% 的证据结构
（满 refill 位置 0-7 ≈1.2% vs 8-15 ≈9.0%，阶跃恰在呈现量子 8；
d4 无后块全指标变好；d2serial 几乎不合批仍退化）与"**研究呈现路径
成本 × 后块位置 / 浅队列调用税**"一致——该成本层（adapter+seam+
整批临界区+决策记录）在产品中不存在，"batching 必然付 p99"未确立。
front-only drain 是 bench 协议且当前更多惩罚 A0（observe tail 24.9
vs 10.4µs）。感知决策表的输入全是 harness 状态，产品无落点。

**候选（按"消除/摊销→服务顺序→控制逻辑"排序）：**

1. **C-A：产品 transport 层 enter 摊销**。研究分支在 master 之上实现
   Q=8 延迟 flush（SQE 照常准备，enter 推迟至量子满或 residue 信号/
   下一个 progress pass），产品路径 A/B 对 A0 产品臂。正式门=R4 全
   口径；保护格 W03-d4、W03-d2serial、W02-d1、W02-d2（浅队列格直接
   检验"无研究层时税是否消失/信号跳代价"）。
2. **关停研究 adapter 线**：结论按范围归档（R 族结论不外推产品）。
   若 C-A 失败即本路线，A0 保持默认。
3. **观察解耦（C-variant2）暂缓**：改变 bench 任务定义与 buffer 依赖，
   且针对 A0 自身弱点而非 R-vs-A0 差。

**唯一下一项 = C-A**（协议见 NEXT_EXPERIMENT.md）。失败即停止该
机制并记录，不进入量子/阈值搜索；候选 B 继续不放行。

理由一句话：它是唯一同时解释 CPU 差、p99 阶跃与浅队列税的最小
干预——把摊销放进已经拥有该义务的层，删掉为观测它而建的整层。
