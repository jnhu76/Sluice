# #595 Flow Audit — 尾延迟竞争解释表（H1–H5 + H6/H7 增补，R2 复核修订版）

符号：[P]=结构已证（源码/确定性检查）；[C]=仅相关（计数/扰动诊断）；
[M]=无测量。所有诊断区间数字继承 PERTURBED 级别（±3pp on/off 窗未过），
不得当作归因。已撤回的 v1 推论见 CORRECTIONS.md R2。

## H1 研究 adapter/准备路径增加了提交前工作（含 back-op 排队）

- 支持：[P] 呈现循环串行无 yield（C5，本轮再确认 `C:r3:468-605`）；
  [P] R 组内 T0=组构建循环内逐成员打点（`ready_ns.push_back(now_ns())`
  `C:bench_w03:413`），全部早于该组任何呈现，back op 延迟含前面全部呈现；
  [C] F5 修正（instrument-on R 相）：满 refill 位置 0-7 尾险 ≈1.2% vs
  8-15 ≈9.0%，阶跃恰在呈现量子 8；占用 8 的 refill 全位 ≈26%。
- 量级（机器复算，替代 v1 的 CPU→串行耗时换算——该换算已撤回：进程
  测量窗口内 CPU 不等于提交线程一段连续路径的 wall time）：MAIN 运行级
  p99 均值差 C−A0 9.52µs / R−A0 10.71µs；逐块相对效应均值 +17.97%/
  +20.14%。该差值与"研究呈现路径成本"的数值关系**未建立**——方向
  一致、量级未分离。
- 反证：无直接反证；W03-d4 C 全面更好（单 chunk 无后块）与此一致。
- 缺观测：无锁内耗时/每呈现固定成本的干净测量；无同批量、同调用数、
  仅换呈现路径成本的对照（识别缺口，见 H4/H7）。
- 区分性反事实：保持 ready 集合、逐请求 T0、分组/顺序、flush 与观察
  路径全部不变，删除一个已证明冗余的研究入口步骤（现无具备语义等价
  证据的候选步骤：NO_COUNTERFACTUAL_SELECTED，NEXT_EXPERIMENT §7）。
- 混杂：二进制布局（A0c−A0o ±1.5%）；诊断扰动；两臂 T0 端点语义差异
  （研究内同 workload，back-op 起点不同是被测机制的一部分）。

## H2 连续 chunk 提交改变完成服务机会/锁竞争

- 支持：[P] 研究整批 `dispatch_mtx_` 临界区 vs driver 每 CQE 短临界区
  （C3 结构）；[P] driver 可在呈现间发布（publication 在锁外），但
  submitter 背靠背重取锁——机会存在、频率未测（[M]）。
- 反证：[C] E12 wake 区间 R≤A0（R 不更晚醒）；[C] E14 T4−T3 仅 +59ns
  （发布延迟非量级来源）；E10 组内 straggle T3 级被否。
- 缺观测：锁持有/等待时间；driver 在 chunk 边界实际获得的次数。
- 区分性反事实：同批量下缩短临界区（分段 admit/dispatch）或提供真
  yield → 若 p99 阶跃缩小则竞争/机会成分成立。
- 混杂：H1 同路径成本无法与锁竞争分离（两者都在呈现边界）。

## H3 caller 顺序观察+资源回收造成头阻塞

- 支持：[P] front-only drain 停在未发布队头（bench 协议）；
  [P] 库允许乱序 take（`M:request.hpp:134-159`）。
- 修正（v1 撤回）：v1 用"A0 observe tail-mean 24.9µs > R 10.4µs"推断
  H3 不能主导 R−A0 p99 差。该推断无效——两臂的 tail set 不同（进入
  尾部的请求集合不同），跨不同集合比较 observe 均值不能分离观察顺序
  对**差值**的作用。现表述：**现有诊断未能分离观察顺序及反馈作用**；
  observe 均值差只说明 latch 当前更多惩罚 A0 自身的尾。
- 缺观测：published-behind-front 的发生频率/时长未测。
- 区分性反事实：any_ready 消费对照（W02 已有诊断开关，W03 未跑）。
- 混杂：改变观察顺序改变的是 bench 任务定义与 buffer 依赖（C6 反例）。

## H4 批量改变 io-wq/内核执行与完成突发

- 支持：[C] io-wq ticks 下界 R/C ≤ A0（采样归类口径）。
- 修正（v1 撤回）："1 enter/8 op ⇒ CQE 更集中 ⇒ pass 聚合粒度变大"与
  "enter 下降必然减少 io-wq 执行"降级为**待检验假设**——enter 数与
  CQE 到达分布、io-wq 路由的关系没有测量支持，不能由 enter 数推出。
- 反证：无直接反证。
- 缺观测：内核完成时刻不可观测（UNAVAILABLE）；完成突发形状无直方图；
  **识别缺口**：v1 提出的"同 enter 数 8×1 vs 2×8"对照同时改变调用数
  与工作量，不能分离任何因素，已删除；同任务、同调用数的形状对照
  无法由现有臂构造。
- 混杂：与 H1/H2 同现于任何批量形态。

## H5 时间起点/位置恢复/join/诊断器扰动放大

- 支持：F5 v1 的 caller_window 误读已证（PR #630 R1 修正）；诊断 on/off
  扰动 −4.9~+9.2pp 全部超窗（PERTURBED）。
- 反证：位置恢复 480,000 行闭合（本轮复核口径：24 个 instrument-on R
  diag tag × 20000 ops，12×d16+12×d4；0 异常、0 gap；冻结恢复脚本
  离线重跑逐位复现派生摘要——派生摘要完整性，非逐请求身份独立重建）。
- 缺观测：干净（无仪器）运行上的位置分布不存在（仪器即扰动）。
- 区分性反事实：off-mode 复跑 ≥3 对（Phase-A 已建议，未执行）。
- 混杂：本身即混杂源；修复后的数字仍只能当 lead。

## H6（增补）浅队列税=研究入口的调用路径成本（非 batching）

- 支持：[P] d2serial max_refill=1 每决策 outstanding()==0 结构零；
  [C] d2serial CPU +3.90%（单侧上界 +4.90 PASS）但吞吐/p95/p99 FAIL，
  几乎不合批仍退化；[P] W02 稳态单 op 呈现（X1）且 W02-d1/d2 全 FAIL；
  [P] R 每呈现付 W15-W19（DecisionRecord/计数/seam/整批锁）。
- 修正：该税的**存在**有结构+计数支持，但其对产品路径的可泛化性未
  验证——产品路径在相同浅队列形状下的等价运行不存在（无反事实）。
- 反证：W02-d2 A/A 精度 PASS 下仍 FAIL → 非纯噪声。
- 区分性反事实：删除研究层单一已证冗余步骤后的浅队列重跑（现无合格
  步骤，见 H1）。

## H7（增补）A0 产品路径自身的 enter 成本

- 支持：[C] R−A0 CPU −21.5%/C−A0 −22.1%（本轮机器复算，原始精度一致）
  ——提交调用批量化在该形状上有净收益的机制有证据；[P] 产品正常非零
  读形状每 op 恰 1 enter（`M:uring_transport.cpp:87`；zero-op/inline/
  retry/control 路径不满足该 1:1，见 FLOW_AUDIT 图A/C）。
- 修正（v1 撤回）："唯一机制级收益是 enter 摊销"与"任何批量形态都能
  拿到收益"不再成立：净 CPU/吞吐效应已在指定形状测得，但 R−A0 之差
  同时含研究路径其他变化，成本节约**尚未完全归因到 enter 调用本身**。
- 缺观测：产品路径实现摊销后的净效应（含 front-op 延迟进入内核的
  p50/p95 风险）；enter 数与尾延迟的分离测量。
- 区分性反事实：无现成设计（C-A 因识别混杂撤回，NEXT_EXPERIMENT §1）。

## 组合判断（R2 修订）

- 净效应已知：d16 上 CPU −22%/吞吐 +28%、p99 +18%（robust FAIL）、
  浅队列税（robust FAIL）；d4 全指标改善。均为 R5 指定形状、过程 CPU
  口径。
- 结构已知：研究路径存在额外入口/锁/记账工作；产品路径结构如
  FLOW_AUDIT 图A/C。
- 归因未知：研究入口工作、锁/完成服务、内核行为（enter/CQE/io-wq）、
  caller 反馈各贡献多少——现有数据不能分离；H3 不能被现有 observe
  均值排除。
- 结论：**"batching 必然付出 p99"未确立；"研究呈现路径成本主导 p99 差"
  同样未确立**——两者都是与证据相容的解释族成员，无单因素识别。
