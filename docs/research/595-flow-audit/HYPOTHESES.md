# #595 Flow Audit — 尾延迟竞争解释表（H1–H5 + H6/H7 增补）

符号：[P]=结构已证（源码/确定性检查）；[C]=仅相关（计数/扰动诊断）；
[M]=无测量。所有诊断区间数字继承 PERTURBED 级别（±3pp on/off 窗未过），
不得当作归因。

## H1 研究 adapter/准备路径增加了提交前工作（含 back-op 排队）

- 支持：[P] 呈现循环串行无 yield（C5，本轮再确认 `C:r3:468-605`）；
  [P] R 组内 T0=构建时刻，back op 延迟含前面全部呈现；
  [C] F5 修正：满 refill 位置 0-7 尾险 ≈1.2% vs 8-15 ≈9.0%，
  阶跃恰在量子 8（前块止于 cap、后块止于 input_exhausted）；
  [C] p99 差 ≈+10.7µs（63.4 vs 53.9）与"呈现 8 op 的研究路径 CPU"
  （C ≈2.5µs/op×8=20µs 量级）一致——方向对、量级同阶。
- 反证：无直接反证；但 W03-d4 C 全面更好（单 chunk 无后块）与此一致
  而非矛盾。
- 缺观测：无锁内耗时/每呈现固定成本的干净测量；无产品路径等价
  批量的对照（C-A 存在前的空白）。
- 区分性反事实：同批量、把呈现路径换成产品级成本（或反之研究路径
  固定、批量改产品入口）→ 阶跃应按成本差缩放。
- 混杂：二进制布局（A0c−A0o ±1.5%）；诊断扰动；T0 语义在两臂本就
  不同端点（研究内同 workload 但 back-op 起点不同——这正是被测
  机制的一部分，不是缺陷）。

## H2 连续 chunk 提交改变完成服务机会/锁竞争

- 支持：[P] 研究整批 `dispatch_mtx_` 临界区 vs driver 每 CQE 短临界区
  （C3 结构）；[P] driver 可在呈现间发布（publication 在锁外），但
  submitter 背靠背重取锁——机会存在、频率未测（[M]）。
- 反证：[C] E12 wake 区间 R≤A0（R 不更晚醒）；[C] E14 T4−T3 仅 +59ns
  （发布延迟非量级来源）；E10 组内 straggle T3 级被否。
- 缺观测：锁持有/等待时间；driver 在 chunk 边界实际获得的次数。
- 区分性反事实：同批量下缩短临界区（分段 admit/dispatch）或提供真
  yield → 若 p99 阶跃缩小则竞争/机会成分成立。
- 混杂：H1 同路径成本无法与锁竞争分离（两者都在呈现边界）。

## H3 caller 顺序观察+资源回收造成头阻塞

- 支持：[P] front-only drain 停在未发布队头（bench 协议）；
  [P] 库允许乱序 take（`M:request.hpp:134-159`）。
- 反证：[C] observe 区间 tail-mean A0 24.9µs > R 10.4µs——latch 目前
  惩罚 A0 更多；R 的 p99 差不能由 H3 主导。
- 缺观测：published-behind-front 的发生频率/时长未测。
- 区分性反事实：any_ready 消费对照（W02 已有诊断开关，W03 未跑）。
- 混杂：改变观察顺序改变的是 bench 任务定义与 buffer 依赖（C6 反例），
  不能当作 backend 优化。

## H4 批量改变 io-wq/内核执行与完成突发

- 支持：[C] io-wq ticks R/C ≤ A0（enter 减少 → io-wq 进入减少）；
  1 enter/8 op ⇒ CQE 更集中 ⇒ pass 聚合粒度变大。
- 反证：无直接反证。
- 缺观测：内核完成时刻不可观测（UNAVAILABLE）；完成突发形状无直方图。
- 区分性反事实：同 enter 数不同批量形状（如 8×1 vs 2×8 对照臂）。
- 混杂：与 H1/H2 同现于任何批量形态；无法用现有数据分离。

## H5 时间起点/位置恢复/join/诊断器扰动放大

- 支持：F5 v1 的 caller_window 误读已证（PR #630 R1 修正）；诊断 on/off
  扰动 −4.9~+9.2pp 全部超窗（PERTURBED）。
- 反证：位置恢复 480k 行 0 异常、seq 连续性校验通过（本轮从
  f5-position.json 复核 validation_totals：anomalous 0 / gap 0）；
  分析脚本 CI 逐位复现。
- 缺观测：干净（无仪器）运行上的位置分布不存在（仪器即扰动）。
- 区分性反事实：off-mode 复跑 ≥3 对（Phase-A 已建议，未执行）。
- 混杂：本身即混杂源；修复后的数字仍只能当 lead。

## H6（增补）浅队列税=研究入口的调用路径成本（非 batching）

- 支持：[P] d2serial max_refill=1 每决策 outstanding()==0 结构零；
  [C] d2serial CPU +3.90%（单侧上界 +4.90 PASS）但吞吐/p95/p99 FAIL，
  几乎不合批仍退化；[P] W02 稳态单 op 呈现（X1）且 W02-d1/d2 全 FAIL；
  [P] R 每呈现付 W15-W19（DecisionRecord/计数/seam/整批锁）。
- 反证：W02-d2 A/A 精度 PASS 下仍 FAIL → 非纯噪声。
- 缺观测：产品路径在相同浅队列形态下的等价运行（无研究层）不存在。
- 区分性反事实：产品层批量入口（C-A）在 d2serial/W02-d1 上的表现；
  若税消失则 H6 成立。

## H7（增补）A0 产品路径自身的可摊销 enter 成本

- 支持：[C] R−A0 CPU −21.5%/C−A0 −22.1%（复算逐位吻合）——唯一稳健
  的机制级收益是 enter 摊销；[P] 产品每 op 恰 1 enter
  （`M:uring_transport.cpp:87`）。
- 反证：无——该项是两轮矩阵一致复现的最大效应。
- 缺观测：产品层实现摊销后的净效应（含 front-op 延迟进入内核的
  p50/p95 风险）。
- 区分性反事实：C-A（transport 层 flush 量子/产品 span 入口）A/B。

## 组合判断

- 净效应已知：d16 上 CPU −22%/吞吐 +28%（robust）、p99 +18%（robust
  FAIL）、浅队列税（robust FAIL）；d4 全指标改善。
- 根因可识别部分：H7 是确定存在的机制；H1 的结构前提全部成立
  （串行化、T0、量子 8 阶跃），量级归属仍为 lead；H2/H4 未分离；
  H3 方向与 R 的 p99 差相反（惩罚 A0）。
- 不可识别（本轮仪器下）：内核完成时刻、锁持有竞争、呈现间发布频率。
- 结论：**"batching 必然付出 p99"未确立**；现有证据与"研究呈现路径
  成本 × 后块位置"解释族一致，且该成本层在产品中不存在。
